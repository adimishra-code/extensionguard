# Privacy Policy for Extension Guard

**Last Updated:** January 2025

## Overview

Extension Guard is a browser extension that helps you monitor the security of your installed extensions. This privacy policy explains what data we collect, how we use it, and your rights.

---

## Data Collection

### What We Collect

#### 1. Local Storage (Stays on Your Device)
- **Extension metadata:** Names, IDs, versions, permissions of installed extensions
- **Risk scores:** Calculated security ratings
- **Alerts:** Security notifications and history
- **Configuration:** Your settings and preferences

#### 2. Optional Cloud Sync (Only if Enabled)
If you choose to enable cloud synchronization with an API key:
- Extension metadata (for threat intelligence analysis)
- Risk scores
- Security alerts
- Your API key (encrypted)

### What We DON'T Collect
- ❌ **Browsing history**
- ❌ **Personal information** (name, email, etc.)
- ❌ **Tab contents or page data**
- ❌ **Passwords or credentials**
- ❌ **Search queries**
- ❌ **Form data**
- ❌ **Cookies from websites you visit**

---

## How We Use Your Data

### Local Analysis
- Calculate risk scores based on extension permissions
- Detect suspicious permission patterns
- Show you security alerts
- Track extension updates

### Optional Cloud Features (If You Enable Sync)
- Compare your extensions against threat intelligence database
- Receive alerts about known malicious extensions
- Contribute to community security (anonymous)
- Advanced differential analysis

---

## Data Storage

### Local Storage
- All data stored in Chrome's local storage
- Encrypted by Chrome browser
- Never transmitted without your permission

### Cloud Storage (Optional)
- Stored on secure servers (details in backend privacy policy)
- Encrypted in transit (HTTPS)
- Access controlled by your API key

---

## Third-Party Services

### When Cloud Sync is Enabled
- **Backend API:** Extension Guard backend (optional)
- **Purpose:** Advanced threat intelligence and analysis
- **Data Shared:** Extension metadata, risk scores

### We Do NOT Use
- ❌ Analytics or tracking services
- ❌ Advertising networks
- ❌ Social media trackers
- ❌ Data brokers

---

## Your Rights and Choices

### Control Your Data
1. **Disable Cloud Sync:** Turn off in settings anytime
2. **Delete Data:** Uninstall extension to remove all local data
3. **View Data:** All data visible in extension popup
4. **Export Data:** Contact us for data export

### Privacy-First Design
- Works completely offline (cloud sync optional)
- No tracking or analytics
- No ads
- Open source code (verify yourself)

---

## Data Retention

### Local Data
- Stored until you uninstall the extension
- You can clear manually in settings

### Cloud Data (If Synced)
- Retained while you use the service
- Deleted 90 days after account inactivity
- You can request immediate deletion

---

## Security

### How We Protect Your Data
- All communications encrypted (HTTPS/WSS)
- API keys never stored in plain text
- No server-side logging of sensitive data
- Regular security audits

### Your Responsibility
- Keep your API key private
- Use strong passwords (if using backend)
- Keep Chrome browser updated
