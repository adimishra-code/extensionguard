# Extension Icons

Placeholder for extension icons. You'll need to add the following icon files:

- `icon16.png` (16x16)
- `icon32.png` (32x32)
- `icon48.png` (48x48)
- `icon128.png` (128x128)

## Creating Icons

You can:
1. Design custom icons using Figma/Sketch/Photoshop
2. Use the Extension Guard shield logo
3. Generate from online icon generators
4. Use placeholder icons temporarily

For now, you can use simple colored squares or the Chrome extension default icon during development.

## Recommended Design

- Use the shield icon from Extension Guard branding
- Primary color: Blue (#2563EB)
- Include a small lock or checkmark symbol
- Keep it simple and recognizable at small sizes
